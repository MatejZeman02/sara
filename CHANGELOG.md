# Changelog

What changed in the base modules, by version. Each release reads the section of the
version the `manifest.cfg` carries, and refuses a release with no such section.

## 1.0.0-alpha.1

Every module of this repository writes its id, name, version, dependencies and a sentence about itself in a `manifest.cfg`, which Sara reads before any of the module's code, and the versions move with each release from here on.
The modules extend `SaModule`, the base class's new name.
A soft selection limits a stamp brush stroke once, as the stroke's opacity does, so dabs that overlap never climb past it.
Box Blur averages across, then down, then blends, so a radius of 200 over a canvas of 4000 by 3000 applies in a third of a second where the square it summed took seven.
Vector layers draw rectangles and ellipses with a fill and a stroke in float colour, through the Shape tool, and the Object tool moves and resizes them, each object listed in the Tool Options docker.
