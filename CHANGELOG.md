# Changelog

What changed in the Czech module, by version. Each release reads the section of the
version the `manifest.cfg` carries, and refuses a release with no such section.
The file is in English, and a Czech message it names is quoted.

## 1.0.0-alpha.1

The Czech release notes moved from `CHANGELOG.md` to `RELEASE-NOTES.md`, with the untouched draft beside them as `RELEASE-NOTES.machine.md`, so this file can say in English what changed in the module. Sara's News pane reads the new name beside the catalogue.
The README is written for people who want Sara in Czech or want to correct it: how to switch the language, that the catalogue is a machine translation only partly checked by a person, and how to report or fix a wording.
The catalogue follows the messages Sara gained since 0.19.1, each with a machine draft marked `#. machine draft, not reviewed`, and the messages reworded so they no longer name a person.
The Czech release notes carry the 1.0.0-alpha.1 section of Sara's changelog line for line, a machine draft marked as not reviewed.

## 0.19.1

The module as Sara 0.19.1 shipped it: a Czech catalogue of every message of Sara's translation template, drafted by a machine and marked unreviewed entry by entry, with Krita's Czech words where Krita has one, such as "Štětec" for Brush and "Vrstvy" for Layers.
The release notes of every version from 0.6.0 to 0.19.1 in Czech, one section for each section of Sara's English notes, each marked `machine draft, not reviewed`. A section with as many lines as the English one shows in Czech and any other shows in English.
The untouched drafts, `cs.machine.po` and the machine copy of the release notes, are kept to compare a correction against.
